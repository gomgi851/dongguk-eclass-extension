# 문제 해결

## 강좌가 불러와지지 않을 때
e-Class 로그인 상태를 먼저 확인하세요. 확장과 학교 페이지를 새로고침한 다음 설정 → 강좌 설정 → 강좌 불러오기를 누릅니다. 진행 중·완료·실패 메시지를 확인하세요. 일부 강좌 실패 시 이전 결과가 유지될 수 있습니다.

## CSP 오류
설정 → 실행 정보에서 실제 실행 버전과 이번 팝업의 CSP 차단 횟수를 확인합니다. 팝업 카운터는 사이트 탭·백그라운드의 모든 오류를 집계하지 않으며 팝업을 새로 열면 초기화됩니다.

Chrome 확장 관리 화면의 오류에서 기존 기록을 모두 삭제하고 확장을 새로고침한 뒤, 팝업에서 같은 동작을 다시 해 보세요. 새로 발생한 오류의 문구·파일명·줄 번호와 실행 버전을 이슈에 적어 주세요. 보안 정책을 완화해서 해결하지 마세요.

## 그리드·다크 모드
확장을 갱신한 다음 열려 있던 학교 페이지도 새로고침하세요. 좁은 콘텐츠 영역에서는 지정한 열 수보다 적게 표시됩니다. 주차 그리드는 지원하는 flexsections 강의실 구조에 적용됩니다.

## 이슈 작성
버전, Chrome 버전, 화면 종류, 재현 순서, 기대 동작, 실제 동작을 적어 주세요. 스크린샷에서는 이름·학번·성적·IP·과제 내용·로그인 정보 등 개인 정보를 가려 주세요. 원본 HTML·쿠키·세션 URL·비밀번호는 첨부하지 마세요.
