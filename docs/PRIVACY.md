# 데이터 처리 안내

대상: Dongguk e-Class v0.7.4. 본 확장은 학교 공식 서비스가 아닙니다.

## 읽고 저장하는 정보
e-Class의 강좌명·주소, 과제명·주소·제출 상태·마감, 동영상명·기간·개별 출석·학습시간을 읽어 학습 현황을 표시합니다. 결과, 마지막 확인 시각, 실패 안내, 강좌 선택, 수집 진행 상태와 테마·필터·주차 보기 설정은 Chrome 로컬 저장소에 저장합니다. 서버가 반환한 페이지 원문 전체는 저장하지 않습니다.

계정 변경 시 이전 결과가 섞이는 것을 줄이기 위해 페이지에 표시된 학번을 일시적으로 읽고 SHA-256 해시로 변환해 로컬에 보관합니다. 학번 원문을 따로 저장하지 않으며 해시가 익명 정보라고 보장하지 않습니다.

## 네트워크와 로그인
학교 서버에는 기존 로그인 세션으로 페이지를 요청합니다. 비밀번호를 입력받거나 저장하는 기능이 없고, 개발자 서버·분석·광고 서비스에 학습 결과나 계정 해시를 전송하는 기능도 없습니다. 학교 서버가 처리하는 로그인과 요청 정보에는 학교 정책이 적용됩니다.

## 삭제와 진단
설정 → 강좌 설정 → 저장 정보 지우기는 학습 결과·강좌 선택·수집 상태를 삭제하며 테마 등 환경설정은 유지합니다. 확장 제거 시 확장 전용 저장소도 삭제됩니다.

CSP 진단은 현재 팝업의 차단 횟수와 최근 최대 5건의 지시문·JavaScript 파일명·줄 번호만 메모리에 표시합니다. 팝업 종료 시 초기화되며 전체 URL·코드 샘플을 저장하거나 전송하지 않습니다. Chrome 자체 오류 기록은 Chrome에서 별도로 관리합니다.
