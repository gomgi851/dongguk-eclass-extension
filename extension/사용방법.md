# Dongguk e-Class v0.7.5

확장 아이콘을 누르면 480×600 크기의 팝업으로 열립니다.

## 업데이트
기존에 로드한 `eclass-checker` 폴더의 파일을 새 파일로 교체한 뒤, `chrome://extensions`에서 확장프로그램의 새로고침 버튼을 누르세요. 저장된 학습 결과는 유지됩니다. 이 작업 폴더에서 그대로 로드했다면 파일 교체 없이 확장 새로고침만 하면 됩니다.

처음 설치한다면 ZIP 압축 해제 → `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → `manifest.json`이 있는 폴더 선택.

## v0.6.4 수정
강좌 불러오기 진행·완료·오류를 설정창 안에도 표시합니다. 수집 문서가 존재해도 메시지 수신 준비가 끝나지 않은 경우 준비를 기다립니다. 초기 수집 연결이 실패해도 저장된 목록은 표시합니다. 실제 설치 환경의 무반응 원인은 아직 확인하지 못했으며, 수정은 준비 지연과 실패 UI를 재현해 검사했습니다.

## 사용
- 크롬에서 e-Class에 로그인합니다.
- 상단 톱니바퀴 아이콘 → **강좌 설정** → **강좌 불러오기** → 선택 → **선택 강좌 확인**.
- 이후 기본 **15분 간격 자동 갱신**으로 확인합니다. **새로고침** 버튼으로 즉시 확인할 수도 있습니다. 확인 중 팝업을 닫아도 수집은 이어집니다. 크롬을 종료하면 중단될 수 있습니다.
- 과제: **미제출 / 제출함 / 전체**. 동영상: **미수강 / 수강함 / 전체**.
- 제출한 과제도 목록에 남습니다. **기한 내** 필터로 좁히고 제목을 눌러 과제 페이지를 열 수 있습니다. 수정 허용 여부는 해당 강의실 설정에 따릅니다.
- 기한이 지난 과제도 **모든 기간**에서 볼 수 있습니다. 판별되지 않은 항목은 **전체** 또는 **확인 필요**에서 확인하세요.
- 결과·강좌 선택·토글은 기기에 저장됩니다. 계정을 바꿀 때는 강좌 설정의 **저장 정보 지우기**를 사용하세요.

## 범위
과제 목록의 제출 상태와 동영상 출석부의 개별 출석을 읽습니다. 주차 출석과 영상 출석은 별개입니다. 퀴즈·설문·공지로만 안내되는 과제·Teams 강의는 포함하지 않습니다. 실패 안내는 설정창의 **확인 안내**에서 펼쳐볼 수 있습니다.

확인 실패·중지 시 이전 결과를 유지하되 **확인 필요**로 표시합니다. 미제출/제출함 집계에서 제외하며, **확인 필요** 버튼 또는 **전체**에서 이전 상태와 확인 시각을 볼 수 있습니다. 로그인 만료 시 다시 로그인한 뒤 새로고침하세요.

## 강의실 전체 주차 보기
설정 → **모든 주차 한 번에 보기** 스위치를 켜세요. 기본값은 꺼짐입니다. 강의실에 있는 주차별 내용을 세로로 펼치며, 위쪽 주차 탭을 누르면 해당 주차로 이동합니다. 끄면 기존 한 주씩 보기로 돌아갑니다. 선택은 이 기기에 저장되고, 이미 열린 지원 강의실에도 반영됩니다.

업데이트 직후에는 확장프로그램을 새로고침한 다음, 이미 열어둔 강의실 페이지도 한 번 새로고침하세요. 현재 동국대 flexsections 주차 탭 구조에 적용하며, 서버에서 제공하지 않는 자료를 불러오거나 활동 내부 숨김을 해제하지 않습니다.

## 사이트 다크 모드
**e-Class 사이트 상단의 다크 모드 스위치**로 켜고 끕니다. v0.7.0부터 확장 설정에서 사이트로 이동했습니다. 팝업 상단 테마와 별도로 저장하며 기본값은 꺼짐입니다. 열린 e-Class 페이지에 즉시 반영되고 다음 방문에도 유지됩니다. 업데이트 직후에는 확장과 기존 e-Class 탭을 한 번 새로고침하세요. 메인·강의실·표·입력창의 색을 변경하며 이미지·영상·외부 문서는 원래 색을 유지합니다. 외부 도메인 또는 iframe 안의 콘텐츠에는 적용하지 않습니다.

실제 메인 페이지 DOM을 참고해 스타일을 작성했고 합성 브라우저 화면에서 색상·켜기/끄기 복원·저장값 유지를 확인했습니다. 여러 모의 페이지의 저장소 변경 반영도 검사했습니다. 실제 설치 확장의 전체 페이지 검증은 별도입니다.

새로고침은 메인 오른쪽의 화살표 아이콘입니다. 마우스를 올리면 설명이 표시됩니다.

## 테마와 글꼴
메인 상단 오른쪽의 해·달 스위치로 라이트/다크 모드를 바꿉니다. 선택한 테마는 저장됩니다.

모든 글씨에는 동봉된 **여기어때 잘난체 2**를 사용합니다. 별도 글꼴 설치가 필요 없습니다. 날짜·필터·설정·안내문도 잘난체 2로 표시합니다.

설정창에 실제 잘난체 로드 여부가 표시됩니다. 저작권 안내와 원문 PDF도 설정에서 확인할 수 있습니다.

**재배포 시 `licenses` 폴더와 글꼴 저작권 안내를 반드시 함께 배포하세요.** 자세한 사항은 `licenses/FONT-NOTICE.md`와 `licenses/Jalnan-Official-Guide.pdf`에 있습니다. 글꼴 파일은 원본을 수정하지 않고 포함했습니다.

## 검증 및 정보 처리
전체 주차 기능은 실제 강의실 DOM을 확인해 구현했고, 합성 브라우저 화면에서 16주차 전체 표시·주차 바로가기·끄기 복원·숨김 유지 동작을 확인했습니다. 수집 모듈은 모의 Chrome API와 HTML로 완료·부분 실패·중지·로그인 만료를 검사했습니다. 합성 사례로 상태·기간 필터와 제출한 과제 표시를 검사했고, 로컬 미리보기에서 과제/동영상·제출 토글과 팝업 크기를 확인했습니다. 실제 크롬 확장 팝업으로 설치 후 실행하는 검증은 별도입니다.
`eclass.dongguk.edu`에만 접근하며 결과는 로컬 저장소에 저장합니다. 제출·수강·완료 상태를 변경하지 않습니다.



## 확장 아이콘
주황색 바탕과 검정 e를 직접 그린 벡터 아이콘입니다. 글꼴 파일이나 외부 아이콘을 사용하지 않습니다. 원본은 icons/source.svg이며 16·32·48·128·512px PNG를 동봉했습니다. 툴바·확장 관리 화면·팝업 헤더에 적용합니다. 학교 공식 로고가 아닙니다.

## v0.6.5 사이트 다크 모드 보정
실제 로그인된 메인·프로그래밍언어론 강의실·과제 목록·과제 상세를 열어 HTML을 확인했습니다. 해당 본문과 학교 스타일시트를 로컬에 재현해 수정 CSS를 적용하고 화면을 점검했습니다. 왼쪽 메뉴·강의실 공지·예정된 할 일 제목·과제 경고·휴대폰 버튼의 배경과 글자색을 보정했습니다. 네 화면에서 검사 대상 텍스트 378개의 계산된 전경색/배경색 대비를 확인했고, 4.5:1 미만으로 탐지된 항목은 최종 검사에서 없었습니다. 이 검사는 배경 이미지·투명도·다른 페이지나 대화상자까지 포함하는 접근성 전체 인증은 아닙니다.

실제 크롬에 설치된 확장으로 모든 페이지를 실행해 검증한 것은 아닙니다. 설치 후 확장과 열린 e-Class 페이지를 새로고침하면 변경 스타일이 적용됩니다. 검증용 페이지 원본과 로그인 정보는 배포 ZIP에 포함하지 않습니다.

## 빈 주차 숨기기와 그리드
전체 주차 보기 기능을 켠 상태에서 강의실 상단의 빈 주차 숨기기 버튼을 사용합니다. 차시 제목만 있는 주차를 숨기며, 활동·자료·안내문·공개 예정 항목이 있는 주차는 유지합니다. 다시 표시 버튼으로 복원합니다. 숨김 상태는 기기에 저장됩니다.

옆의 아이콘 버튼에서 목록·2열·4열·8열·AUTO를 선택합니다. 마우스를 올리면 설명이 표시됩니다. 16주차 기준 2열은 8행, 4열은 4행, 8열은 2행입니다. 빈 주차를 숨기면 행 수가 달라집니다. 콘텐츠 영역 폭이 좁으면 선택한 열 수보다 적게 표시해 읽을 공간을 확보합니다.

## 업데이트 기록
설정의 업데이트 내역 링크 또는 CHANGELOG.md에서 버전별 변경 내용을 확인합니다. 배포 ZIP에는 변경 내역과 글꼴 라이선스·아이콘 원본을 함께 포함합니다.


## 현재 주차 강조
과제 목록의 학사 기간을 읽을 수 있으면 현재 주차에 이번 주 배지와 주황색 테두리를 표시합니다. 학사 기간이 없으면 초기 선택된 주차에 선택됨 배지를 표시합니다. 현재 주차는 내용이 없어도 빈 주차 숨기기에서 유지됩니다.


## CSP 오류 확인
설정 → 실행 정보에서 실행 버전(v0.7.5)과 이번 팝업의 CSP 차단 횟수를 확인합니다. 카운터는 팝업을 새로 열 때 초기화되며, 백그라운드·사이트 탭의 모든 오류를 세는 기능은 아닙니다.

Chrome의 확장 오류 화면에서 기존 기록을 모두 삭제하고 확장을 새로고침한 후 팝업을 다시 열어 같은 동작을 반복하면 새 오류인지 구분할 수 있습니다. 새 차단이 발생하면 실행 정보에 지시문·파일명·줄 번호가 표시됩니다. 오류를 숨기거나 CSP를 완화하지 않습니다.


## v0.7.5 확인 필요와 갱신 상태
메인의 확인 필요 버튼은 현재 선택한 과제/동영상 종류에서 상태를 판별하지 못한 항목의 개수를 표시합니다. 누르면 해당 항목만 모아 봅니다. 감지한 미지원 이러닝 콘텐츠는 완료·미수강을 추정하지 않고 직접 확인하도록 표시합니다.

새 학습 확인을 시작하면 이전 카드는 이전 결과로 표시되며 이번 확인에 성공한 항목부터 갱신됩니다. 로그인 만료·중지 후에도 미확인 결과의 표시를 유지합니다. 확인 시각에 마우스를 올리면 마지막 전체 확인 시각을 볼 수 있습니다.

현재 주차는 저장된 학사 기간과 한국 날짜로 1분 간격 및 탭 복귀 시 다시 계산합니다. 기간 조회 실패는 최대 2회 자동 재시도하며, 이후 탭 복귀 등에서 다시 확인할 수 있습니다.

## 백그라운드 자동 갱신
설정 → **백그라운드 자동 갱신**에서 켜고 끕니다. 기본값은 켜짐·15분입니다. 갱신 간격은 5·15·30·60분 중 선택하며 기존에 선택한 강좌만 확인합니다. 강좌 선택과 첫 확인을 완료한 뒤 사용하세요.

팝업이 닫혀 있어도 Chrome 알람으로 동작합니다. Chrome 종료·절전 중에는 확인할 수 없으며 예정 시각보다 지연될 수 있습니다. 자동 조회에서 로그인 만료를 만나면 오류 안내 없이 이번 회차를 건너뛰고 기존 결과와 확인 시각을 유지합니다. 이후 주기에 다시 시도하므로 학교 사이트에 다시 로그인하면 별도의 새로고침 없이 다음 주기에 반영됩니다. 직접 새로고침할 때의 로그인 만료 안내는 유지합니다.

자동 갱신은 로그인된 학교 서버에 읽기 요청을 보내며 제출·재생·이수 상태를 변경하지 않습니다. `alarms` 권한은 정기 실행 예약에만 사용합니다. [Chrome 알람 동작 안내](https://developer.chrome.com/docs/extensions/reference/api/alarms)
