# 업데이트 내역

## 0.7.5 · 2026-11-11

- 선택한 강좌를 기본 15분 간격으로 확인하는 백그라운드 자동 갱신 추가. 설정에서 ON/OFF 및 5·15·30·60분 간격 선택.
- 팝업을 닫아도 Chrome 알람으로 갱신하며, 브라우저 재시작·확장 업데이트 후 예약 복구. 확인 중이거나 최근 수동 갱신한 경우 중복 조회 방지.
- 자동 조회 중 로그인 만료 시 안내 없이 이번 갱신을 건너뛰고 기존 결과·확인 시각 유지. 다음 주기에 다시 확인하여 로그인 복구 후 수동 클릭 없이 갱신.
- 알람 예약·간격 변경·선택 강좌·중복 방지·로그인 만료 후 재개 테스트와 팝업을 닫은 실제 MV3 알람 실행 검사 추가.
- Chrome alarms 권한 및 자동 조회 동작을 사용·개인정보 처리 문서에 기재.

## 0.7.4 · 2026-11-11

- 갱신 실패·중지로 남은 이전 과제/영상은 현재 미제출·수강 상태로 단정하지 않고 확인 필요로 표시. 이전 상태와 확인 시각은 카드에 별도 안내.
- 갱신하지 못한 항목을 미제출/제출함 집계에서 제외하고 확인 필요 버튼으로 모아 볼 수 있도록 수정.
- 과제 목록 갱신에 성공하면 다른 출석부 조회가 실패해도 제출 완료 상태를 즉시 반영하는 회귀 테스트 추가.
- 갱신 실패 후 미제출 오표시 방지와 팝업 안내·필터 동작을 자동 검사. 실제 계정의 과제 상세와 목록에서 제출 완료 표시 및 표 구조를 읽기 전용으로 비교했으며 개인정보는 저장소에 포함하지 않음.

## 0.7.3 · 2026-11-11

- 이러닝 콘텐츠 등 미지원 학습 형식을 확인 필요 항목으로 표시하고, 지원하지 않는 자료나 상태 판별 불가 항목이 있으면 전체 확인 완료로 표시하지 않도록 개선.
- 새로고침 시작 시 이전 결과를 미확인 상태로 표시하여 초기 로그인 만료·중지 후에도 카드별 이전 결과 안내 유지.
- 메인 팝업에 확인 필요 개수와 바로 보기 버튼 추가. 마지막 전체 확인 시각을 확인 시각의 도움말에 표시.
- 동영상 연결 시 자료 ID를 우선 사용하고, 제목이 같으면 주차·차시로 구분. 모호한 경우 강좌 홈 연결 유지.
- 현재 주차를 한국 날짜 기준으로 주기적·탭 복귀 시 재계산하고, 학사 기간 조회 실패 시 최대 2회 자동 재시도. 전체 주차 보기를 끄면 강조 배지 제거.
- 수집·연결·날짜 경계 회귀 테스트 보강 및 실제 MV3 확장을 로드한 Chromium 팝업/CSP·라이트/다크·그리드 검증을 CI·릴리스에 추가.
- 팝업 테마 전환 시 버튼 배경 전환 애니메이션으로 잠시 흰 배경과 밝은 글자가 섞이는 현상 완화.
- 검증용 화면과 네트워크는 합성 자료를 사용하며 실제 학생 계정 정보는 테스트·배포에 포함하지 않음.

## 0.7.2 · 2026-11-08

- 주차 그리드에서 제한 안내·추가 설명이 제목 옆의 별도 열을 차지하지 않도록 전체 폭의 아래 줄로 배치.
- 링크 대신 일반 텍스트로 표시되는 미공개 활동 제목의 그리드 위치 보정.
- 실제 강좌 구조에 제한 안내가 내부·외부에 있는 사례와 링크 없는 사례를 추가한 재현 화면에서 라이트·다크 및 2·4·8열·AUTO 검사. 학교 로그인 세션 만료로 해당 강좌의 실시간 설치 확장 검증은 미실시.

## 0.7.1 · 2026-11-08

- 설정의 실행 정보에 실제 실행 버전과 현재 팝업 세션의 CSP 차단 횟수 표시.
- CSP 위반 발생 시 지시문·파일명·줄 번호만 기기 화면에 표시. 코드·URL·개인정보를 저장하거나 전송하지 않음.
- 배포 HTML의 인라인 이벤트·인라인 스크립트·javascript 주소 및 실행 가능한 HTML 삽입 여부 검사 추가.
- 엄격한 CSP의 로컬 팝업에서 설정 열기·닫기, 테마, 제출 상태, 기간, 주차 토글, 모의 강좌 불러오기 동작 후 CSP 차단 0건 확인.

보고된 Chrome 오류의 정확한 발생 경로는 아직 확정하지 못했습니다. 저장된 이전 오류와 새 실행 오류는 기존 오류 기록을 비운 뒤 재현해서 구분해야 합니다. 실제 설치 확장 검증을 대체하지 않습니다.

## 0.7.0 · 2026-11-08

- 사이트 다크 모드 스위치를 확장 설정에서 e-Class 상단으로 이동.
- 출석부·성적부 탭, 게시판 목록·글 상세·첨부파일, 글쓰기 편집기 등 다크 모드 적용 범위 확대.
- 강좌 목록 외곽선과 영역 구분선을 어두운 갈색으로 조정.
- 강의실에 빈 주차 숨기기/다시 표시 버튼 추가. 자료·안내문·공개 예정 활동이 있는 주차는 유지.
- 주차 보기 아이콘 추가: 목록, 2열, 4열, 8열, 맨 오른쪽 AUTO. 좁은 화면에서는 열 수 자동 축소.
- 강의실 바로가기와 주차 보기 도구를 같은 줄에 배치하고 도구 모음 디자인 통일.
- 주차 보기 도구를 오른쪽에 정렬하고 불필요한 주차 이동 안내 문구 제거.
- 학사 기간으로 확인한 현재 주차를 두 테마에서 강조. 기간을 확인할 수 없으면 선택된 주차로 구분해 표시.
- 그리드의 기존 들여쓰기와 제목·아이콘 겹침 보정. 제목과 이수 상태는 같은 줄, 기간은 다음 줄에 배치.
- 버튼·토글 이벤트 등록을 addEventListener로 통일.
- 설정에서 업데이트 내역을 열 수 있도록 추가.

검증: 실제 학생용 페이지의 본문과 학교 스타일을 로컬에 재현해 다크 모드를 점검. 팝업은 script-src 'self' CSP와 모의 Chrome API로 버튼·토글·강좌 불러오기 흐름을 검사. 실제 설치 확장에서 모든 강좌·게시글·첨부 문서 내부를 실행한 검증은 아님.
