# 화면 색상

사용자가 제공한 Pantone 팔레트를 기준으로 구성했습니다. 아래는 인쇄용 색상과 동일한 색을 보증하지 않는 화면용 근사값입니다.

| 기준 | HEX |
|---|---|
| 159 C | #CB6015 |
| Warm Gray 7 C | #968C83 |
| Warm Gray 9 C | #83786F |
| 124 C | #EAAA00 |
| 173 C | #CF4520 |
| 144 C | #ED8B00 |

참고: [Pantone C 색상표](https://www.convertcase.com/colors/pantone-c-color-chart).

기본 테마는 주황·블랙입니다. 주황색 버튼·브랜드와 검정 배경, 주황색 빛 번짐을 사용합니다. 글자 가독성을 위해 원색의 밝기·투명도를 조정한 파생색도 사용합니다. 메인 상단 해·달 스위치로 주황·화이트의 라이트 테마로 전환할 수 있습니다.
